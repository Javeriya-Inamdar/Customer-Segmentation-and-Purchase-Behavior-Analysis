# Customer-Segmentation-and-Purchase-Behavior-Analysis
Data Analysis project showcasing customer behavior using python, SQL and Power BI

Overview

This project focuses on analyzing customer shopping behavior to uncover meaningful business insights related to customer preferences, spending patterns, product performance, and revenue trends.

The workflow covers the complete data analytics lifecycle — from data cleaning and exploratory data analysis (EDA) in Python to SQL-based business analysis and interactive dashboard creation in Power BI.

The project aims to support data-driven decision-making by identifying high-value customers, customer segments, top-performing products, and key revenue contributors.

Dataset

The dataset contains transactional customer shopping data collected from a retail environment.

Dataset Highlights
Customer demographics (Age, Gender, Location)
Product information (Category, Item Purchased, Size, Color)
Purchase details (Purchase Amount, Shipping Type, Discounts)
Customer behavior metrics (Subscription Status, Previous Purchases, Review Ratings)
Dataset Size
Rows: 3,900+
Columns: 18

Project Workflow
1. Data Loading & Exploration
Loaded dataset using Pandas
Checked data structure and summary statistics
Identified missing values and inconsistencies
2. Data Cleaning
Handled missing values in review ratings
Renamed columns for consistency
Removed redundant columns
Standardized categorical values
3. Feature Engineering
Created customer age groups
Derived purchase frequency metrics
Prepared data for SQL analysis and dashboarding
4. Exploratory Data Analysis (EDA)

Performed analysis to identify:

Revenue distribution
Customer purchase trends
Product popularity
Spending behavior across demographics
Subscription-based purchasing patterns
5. SQL Business Analysis

Executed SQL queries to answer business questions such as:

Revenue by gender
High-spending discount users
Top-rated products
Shipping type comparison
Customer segmentation
Repeat buyer analysis
Revenue contribution by age group
6. Dashboard Development

Built an interactive Power BI dashboard featuring:

KPI Cards
Revenue Analysis
Sales by Category
Customer Segmentation
Subscription Insights
Revenue by Age Group
Interactive Filters & Slicers
Dashboard

Key Results & Insights
Non-subscribers contributed higher total revenue compared to subscribers
Express shipping users showed higher average purchase amounts
Loyal customers formed the largest customer segment
Clothing category generated the highest sales
Young adults contributed the highest revenue among all age groups
